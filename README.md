# LL Caixa

App de caixa, estoque e vendas da **LL Original** (PWA, funciona offline).

- Contexto e decisões: [`CLAUDE.md`](CLAUDE.md)
- Como colocar no ar: [`docs/CONFIGURAR.md`](docs/CONFIGURAR.md)

```bash
npm install
npm run dev     # http://localhost:3000 (modo local se não houver .env.local)
npm test        # regras de cálculo
npm run build
```
